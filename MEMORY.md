# Memory index and rules

Local root: the project root containing AGENTS.md; resolve all paths relative to that root (currently /workspace). Initialized 2026-11-13 using user-authorized provisional defaults.

## Read at session start
- IDENTITY.md: assistant role and boundaries.
- USER.md: confirmed context and provisional preferences.
- MEMORY.md: this index and retention rules.
- STATE.md: current objective, progress, and next actions.

## Consult when relevant
- memory/facts.md: durable verified facts with sources and dates.
- memory/decisions.md: decisions, rationale, and scope.
- memory/hypotheses.md: unverified ideas and what would confirm or refute them.
- memory/lessons.md: reusable lessons supported by experience.
- research/: topic-specific investigations; create notes only for actual work.

## Retention
- Store concise, useful durable knowledge rather than conversation transcripts.
- Distinguish user statements, observed evidence, inferences, and provisional defaults.
- Record sources and dates for consequential entries. Preserve meaningful history when correcting or updating a record.
- Keep temporary work under work/; update STATE.md for handoff.
- Do not store credentials, secrets, or unnecessary sensitive personal information. Seek explicit authorization before retaining sensitive data.
- Never copy, synchronize, or publish memory to external services or repositories without explicit destination-specific authorization.
- Files support continuity only when available in a future session; do not promise automatic persistence elsewhere.
